# Monitor WhatsApp — descargas

Página de descarga de Monitor WhatsApp, una app de escritorio (Mac y Windows) de control
transparente del WhatsApp de un hijo: avisa cuando aparecen palabras de riesgo, contactos
nuevos o mensajes borrados. Todo queda en la compu de quien la usa.

- Página: https://aniballujan.github.io/monitor-whatsapp-descargas/
- Instaladores: sección [Releases](../../releases/latest).

No está afiliada, asociada ni respaldada por WhatsApp ni por Meta Platforms.
